Desde la interfaz de VS Code.
1. Pulsa la combinación de teclas Ctrl + Shift + P (o F1).
2. Escribe la frase Python: Select Interpreter (Seleccionar intérprete) y pulsa Enter.
3. Te aparecerá una lista desplegable. Tienes que buscar y hacer clic en la opción que corresponda a tu entorno. Debería poner algo parecido a: Python 3.1x.x   ('soundscape_env': venv) .\soundscape_env\Scripts\python.exe.
4. Una vez seleccionado, cierra la terminal que tienes abierta ahora mismo (puedes darle al icono de la papelera en la ventana de la terminal) y abre una nueva yendo al menú de arriba: Terminal -> New Terminal.
5. Si todo ha ido bien, al abrirse la nueva terminal deberías ver que pone (soundscape_env) justo al principio de la línea.
